# KAIONEX web

Premium marketing website for the KAIONEX connected business software ecosystem by [Techloom.ai](https://techloom.ai).

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality

```bash
npm run lint
npm run build
```
